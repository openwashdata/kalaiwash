# Changelog

## kalaiwash (development version)

- The package metadata now carries discovery keywords, the place and the
  period the data cover (four districts of Nampula Province, 13 November
  2024 to 26 June 2025), and the citation files describe the package as
  a dataset ([\#4](https://github.com/openwashdata/kalaiwash/issues/4)).
- The data dictionary lists the answer options of the 12 HWISE items as
  they appear in the data (Never, Rarely, Sometimes, Often, Always) and
  gives each variable one type. The data are unchanged
  ([\#7](https://github.com/openwashdata/kalaiwash/issues/7)).
- The documentation names the source of the data and how they were
  collected, states the size of the dataset, and gives a usage example
  on the help page
  ([\#10](https://github.com/openwashdata/kalaiwash/issues/10)).
- The package check now also runs on the development branch, so changes
  are checked before they reach the published version
  ([\#12](https://github.com/openwashdata/kalaiwash/issues/12)).
